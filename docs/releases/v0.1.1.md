# ScCode v0.1.1

发布日期：2026-10-19。Windows x64 本地未签名构建，属于开发验收版本。

## 新增

- 真实 VSCode Node 扩展宿主（实验开关 `SC_CODE_REAL_EXT_HOST=1`），通过 `PersistentProtocol` + WebSocket 与工作台通信；默认仍使用旧宿主。
- 免安装发布 zip：`ScCode_0.1.1_x64-unpack.zip`，解压后直接运行 `ScCode.exe`。
- `npm run perf:baseline` 冷启动/内存基线；生产前端 `smoke:dist` 冒烟。

## 变更

- 工作台设置/UI 状态在桌面版改用 profile 内 SQLite，首次启动从 IndexedDB 一次性迁移。
- Go agent server 与 WASM 运行时改为懒启动/懒初始化。
- 产品版本升至 0.1.1；保留 VS Code API 1.110.0 与既有命令/设置 ID 兼容。

## 修复

- Release 包启动黑屏（分包循环导致 TDZ）：恢复 `base/platform/editor` 单一 core，仅拆 `terminal/xterm`，并增加生产构建 headless 冒烟。
- 真实宿主启动时扩展列表为空（磁盘扩展在首次扫描前注册）；Windows `\\?\` 路径传给 Node 导致 `EISDIR`。
- `storage_list` 命令未注册导致 SQLite 存储读取为空。
- 真实宿主下未移植的 comments/timeline/browserView 相关客户被移除，避免崩溃。

## 产物

- `ScCode_0.1.1_x64-setup.exe`：NSIS 安装包。
- `ScCode_0.1.1_x64-unpack.zip`：完整免安装目录；解压到任意位置后运行 `ScCode.exe`，需已安装 Microsoft Edge WebView2 Runtime。用户数据默认仍在 `%APPDATA%\ScCode`（可用 `SC_CODE_HOME` 指定），不是目录内 portable 模式。

## 已知边界

- 未签名；真实旧数据迁移、完整 GUI 与第三方扩展矩阵尚未全量验收。
- 真实扩展宿主仍为实验路径，多窗口宿主隔离、评论/时间线/浏览器视图等 API 未移植。
- CSP/workspace trust、持久 journal、跨文件事务、共享 LSP/index 仍待后续版本。
