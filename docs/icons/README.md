# ScCode 图标（D 版）

控制台窗口铺满画布，圆角外透明；保留白色 S 与淡紫 C，采用实色标题栏、提亮加粗的窗口轮廓，以及更明显的 `>_` 控制台提示符。

## 文件

- `sc-code.svg`：可编辑矢量源，512 × 512 viewBox；无字体、脚本或外部依赖。
- `sc-code-1024.png`：大尺寸预览与复用。
- `sc-code-{512,256,128,64,48,32,16}.png`：应用图标、网页图标等常用尺寸。
- `sc-code.ico`：Windows 多尺寸图标，包含 16、24、32、48、64、128、256 px 七个 32 位 RGBA PNG 帧；24 px 帧仅内嵌于 ICO。

## 编辑与导出

- 窗口主体：`#272132`。
- 实色标题栏：`#675477`；窗口边框及分隔线：`#b59bcf`。
- S 字形：`#f7f2fc`；C 字形及下划线光标：`#c19aff`；提示箭头：`#e8d9ff`。
- 窗口圆角之外透明，窗口内部不透明；不绘制独立的外层底板。
- 本目录 SVG 是本套导出资源的唯一图形源；修改矢量后应重新导出全部 PNG 和 ICO。
- PNG 与 ICO 各尺寸均由 SVG 独立渲染，不将大图逐级缩小，以保留小尺寸细节。

## 范围

- 文件规格参考 `sc-browser/docs/icons`，但图形与配色独立属于 ScCode；没有改动 ScBrowser 资源。
- 本目录保存用户选定的 D 版图标，并作为应用图标的导出源。
- 当前已替换 `public/sc-code.svg` 与 `src-tauri/icons/`；About、标题栏和 favicon 直接使用 `public/sc-code.svg`，桌面图标使用本包导出的 PNG/ICO 及由同一 SVG 生成的 ICNS。
