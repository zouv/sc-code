# v0.1.3-custom.3

**基于上游**：Sidenai/sidex `main@ad978652`（v0.1.3-dev）

> Windows x64 本地打包版本，包含 MSI 与 NSIS 安装包。

## 自定义改动

- 将用户设置路径统一到 `%APPDATA%\\SideX\\User\\settings.json`，迁移旧设置时保留原文件与 JSONC 内容，不覆盖已有目标；Workbench 与 Rust settings consumer 使用相同配置文件。
- 修复 VAC 等 Node 扩展无法读取 Workbench 用户配置的问题：将有效配置快照同步给独立 Node 扩展宿主，并在配置确认前阻止 VAC 激活；支持配置变化和重连同步。
- 配置快照按完整值替换、正确处理删除回退；修复 Node `workspace.getConfiguration()` 对嵌套 section 与 dotted keys 的读取，并增加激活时序测试。
