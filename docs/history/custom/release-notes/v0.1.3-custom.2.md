# v0.1.3-custom.2

**基于上游**：Sidenai/sidex `main@ad978652`（v0.1.3-dev）

> Windows 本地打包版本，包含 MSI 与 NSIS 安装包。

## 自定义改动

- 支持将 `.code-workspace` 拖入 SideX 打开为多根工作区，同时保留 `.vsix` 拖放安装。
- 新增 `workspace` URL 路由；单文件夹 `folder` 路由保持兼容，并在工作区类型切换时清理旧参数。
- 沿用 v0.1.3-custom.1 的 VSIX 安装能力及相关文件资源读取修复。
