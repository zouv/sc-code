# v0.1.3-custom.5

**基于上游**：Sidenai/sidex main@ad978652（v0.1.3-dev）

## 自定义改动

- **修复启动死锁（关键）**：上次会话的侧边栏若停在扩展视图容器（如 VAC），工作台 restore 会卡在等待扩展注册上，而扩展注册又依赖 restore 完成，形成闭环——表现为扩展宿主不启动、插件栏为空、点击扩展容器无反应（全程无报错）。现已打破该环（`CUSTOM-20261016-001`）。
- **修复 release 包看不到已装扩展**：前端扩展「已安装」记录按 origin 隔离（dev `http://localhost:1420` vs release `https://tauri.localhost`），导致 dev 里装的扩展在 release 里不可见。新增启动同步：把磁盘扩展幂等补登记进当前 profile（`CUSTOM-20261015-003`）。
- **Help → About 显示 SideX 版本号**：显示 `0.1.3-custom.5`，同时保持 `productConfiguration.version` 为 `1.110.0` 以免破坏扩展 `engines.vscode` 兼容性（`CUSTOM-20261015-004`）。
- **新增 release 打包脚本**：`CUSTOMIZATIONS/scripts/build-release.bat`（等价 `node CUSTOMIZATIONS/scripts/release.js`）只打包、不改版本号（`CUSTOM-20261015-005` / `CUSTOM-20261016-002`）。
