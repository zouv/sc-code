# 02 · 使用说明（部署 / 维护 / 调试）

> 面向使用者/维护者的操作手册。技术选型见 [`01-技术栈说明.md`](01-技术栈说明.md)；代码在哪、怎么连见 [`../ARCHITECTURE.md`](../ARCHITECTURE.md)。

## 0. 一分钟速览

| 你要做的事 | 命令 / 入口 |
|---|---|
| 安装依赖 / 准备运行时 | `setup.bat` 或 `sh manager.sh setup` |
| 前台运行 Debug | `run.bat` 或 `sh manager.sh dev` |
| 前端工作台开发 | `npm run dev` / `sh manager.sh web` |
| 构建 / 打包 | `build.bat` / `package.bat`（`sh manager.sh build|package`） |
| 测试 / 交付前检查 | `test.bat` / `verify.bat`（`sh manager.sh test|verify`） |
| 文档体检 | `sh manager.sh docs` |

完整命令与参数见根 [`README.md`](../README.md) 的「从源码构建」与「manager.sh 命令一览」。

# 一、部署

## 1. 前置条件

- Node.js 22、npm、Rust stable、MSVC C++ 构建工具、WebView2。
- 构建 Go Agent 需要 Go 1.26+ 与支持 CGO 的 C 编译器；工具路径可用 `SC_CODE_GO_BINARY` / `CC` 指定。
- Windows 10+ x64；其它平台的验证状态见 CI 与发布说明。

## 2. 构建 / 打包

```powershell
.\setup.bat
.\run.bat
.\package.bat
```

产物在 `dist/dev/` 与 `dist/release/`（Debug zip、自包含 unpack 目录、unpack zip、setup.exe）。

---

# 二、维护

- `dist/`、`node_modules/`、`src-tauri/target/`、`.runtime/` 都是产物，不入库。
- 发版前跑 `verify.bat`（测试 + runtime / 本地服务 / 文档检查），再 `package.bat`。
- 版本号与发布说明按仓库约定维护；不要手工改安装包内容。
- 用户数据 / 配置按项目约定放用户目录，不写安装目录。

---

# 三、调试

- 桌面启动失败：看 `run.bat` / `tauri dev` 终端与 `dist` 日志；确认 WebView2 与 MSVC 运行时。
- 前端白屏：先 `sh manager.sh build` 重新生成前端产物；开发期用 `npm run dev` 看控制台。
- 扩展 / agent 问题：确认 Node 扩展宿主与 Go agent 已按 `setup.bat` 准备；`sh manager.sh test` 覆盖核心回归。
- 文档体量或交叉引用问题：`sh manager.sh docs`；语义漂移用 `doc-audit`。
